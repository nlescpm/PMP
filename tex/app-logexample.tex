\section{Example of the project log}
\label{app:example-log}
The following example illustrates one possible way of maintaining a project log. The format is intentionally flexible
and may be adapted to the needs of the project, provided it offers a clear chronological record of significant project
events, decisions, and references to supporting documentation.

\medskip
{\large\bfseries Running log for Project XXX}
\medskip

    The publication was accepted for publication, registered in the RSD, and added to the Netherlands eScience Center

    \item \textbf{2027-01-24 -- SURF infrastructure approved}
    The SURF allocation was approved. The project will use Research Cloud for development and Snellius for
    production-scale computations.
    \item \textbf{2027-01-07 -- SURF infrastructure request submitted}
    A request for SURF compute and storage resources was submitted based on the agreed Technology Plan.
    \item \textbf{2026-11-28 -- Project meeting}
    In preparation for the project review, the project team met to discuss progress and prepare the presentation slides.
    \item \textbf{2026-10-25 -- Project meeting}
    Meeting with external stakeholders to discuss the project progress and next steps. 
    \textbf{Agreements:}
    \begin{itemize}
        \item merge project development branch to master after adding new testing.
        \item prepare a joint presentation for the project review.
    \end{itemize}
    \item \textbf{2026-06-25 -- Project stalled, LA unavailable until 2026-09-01}
