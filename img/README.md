# Images

This directory contains the graphical assets used by the Project Management Protocol.

# Editing workflow

Whenever possible, figures should be maintained in their original editable format (e.g. PowerPoint or LaTeX/TikZ) 
and exported to PDF for inclusion in the LaTeX document.

Avoid editing exported PDF or PNG files directly.
